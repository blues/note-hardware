# Cygnet v1.2 — KiCad format

This directory contains the design files for the Blues **Cygnet** v1.2 (STM32
Feather-format host board) in **KiCad 9** format. They were generated by
porting the original Altium Designer design files and checked against the
shipped BOM, the Altium board's own netlist, and the production gerbers — which
match on every layer **except inner layer 1**. See
[`documentation/Porting-Notes.md`](documentation/Porting-Notes.md) and
[`validation/`](validation/).

> ## ⚠️ Do not manufacture from this port
>
> **Inner layer 1 (`In1_Cu`) does not match the shipped fabrication data.** It
> carries roughly fifty annular rings that the production `*.G1` does not —
> **10.5 % of the drawn area on that layer** — so its fabrication equivalence is
> **not proven** and the harness's gerber gate fails this board on purpose.
>
> Everything else checks out: outer copper, `In2_Cu`, paste and mask all match,
> the schematic netlist is 59/59 exact against the Altium board, ERC and DRC are
> clean, and the BOM matches all 78 refdes. So this port is sound as an
> **electrical reference** — schematic, connectivity, parts — and it is the
> inner-layer copper output that is unverified.
>
> The cause and what would resolve it are in
> [`documentation/Porting-Notes.md`](documentation/Porting-Notes.md#import-quirks-and-fixes).
> For fabrication, use the original package at
> [`../Cygnet Gerbers.zip`](../Cygnet%20Gerbers.zip) instead.

## Contents

| Path | Description |
|---|---|
| `Cygnet.kicad_pro` / `Cygnet.kicad_prl` | KiCad project (rules match the shipped Altium `.RUL`) |
| `Cygnet.kicad_sch` | Root schematic |
| `Cygnet_CPU.kicad_sch`, `Cygnet_Power.kicad_sch`, `Cygnet_Feather-Connector.kicad_sch` | Child sheets |
| `Cygnet.kicad_pcb` | 4-layer board (castellated; zone fills preserved from the Altium import — do not refill) |
| `Cygnet.kicad_wks` | Drawing sheet (shared Blues template) |
| `Cygnet-altium-import.kicad_sym` / `Cygnet-altium-import.pretty/` | Project symbol/footprint libraries captured during the import |
| `sym-lib-table` / `fp-lib-table` | Library tables (the original Altium lib nicknames are aliased to the project library) |
| `documentation/` | Porting notes and plotted schematic/board PDFs |
| `manufacturing/Cygnet_RevA.zip` | Gerbers + Excellon drills exported from KiCad. **⚠️ Reference only — not for production.** Its `In1_Cu` layer does not match the shipped fabrication data (see the warning above). The authoritative production package is [`../Cygnet Gerbers.zip`](../Cygnet%20Gerbers.zip) |
| `validation/` | ERC/DRC reports, per-layer gerber diffs, BOM comparison, Altium netlist cross-check, KiCanvas screenshots |

The project is self-contained. Note: the buttons labelled BOOT/RST/USER on
the silkscreen are SW1/SW2/SW3 in this port (KiCad annotation rules); the
shipped BOM's designators are mapped accordingly during validation.
