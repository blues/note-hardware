# Notecarrier-XI v1.4 — KiCad format

This directory contains the design files for the Blues **Notecarrier-XI**
v1.4 in **KiCad 9** format. They were generated by porting the original
Altium Designer design files in [`../Altium/`](../Altium/) and validated
against the shipped BOM, the production gerbers, and the shipped ODB++
netlist — see
[`documentation/Porting-Notes.md`](documentation/Porting-Notes.md) and
[`validation/`](validation/).

## Contents

| Path | Description |
|---|---|
| `Notecarrier-XI.kicad_pro` / `Notecarrier-XI.kicad_prl` | KiCad project |
| `Notecarrier-XI.kicad_sch` | Root schematic |
| `Notecarrier-XI_IO-Connection.kicad_sch`, `Notecarrier-XI_Notecard-Connection.kicad_sch`, `Notecarrier-XI_Power.kicad_sch`, `Notecarrier-XI_Starnote-Connection.kicad_sch` | Child sheets (the Altium cover and block-diagram sheets are not ported) |
| `Notecarrier-XI.kicad_pcb` | 4-layer board (positive GND/POWER inner planes; zone fills preserved from the Altium import — do not refill) |
| `Notecarrier-XI.kicad_wks` | Drawing sheet (shared Blues template) |
| `Notecarrier-XI-altium-import.kicad_sym` / `Notecarrier-XI-altium-import.pretty/` | Project symbol/footprint libraries captured during the import |
| `sym-lib-table` / `fp-lib-table` | Library tables (the original Altium lib nicknames are aliased to the project library) |
| `documentation/` | Porting notes and plotted schematic/board PDFs |
| `manufacturing/Notecarrier-XI_RevA.zip` | Gerbers + Excellon drills exported from KiCad (authoritative production package: [`../PCB + 3D + 2D/FAB/`](../PCB%20%2B%203D%20%2B%202D/FAB/) ) |
| `validation/` | ERC/DRC reports, per-layer gerber diffs, BOM comparison, ODB++ netlist cross-check, KiCanvas screenshots |

The project is self-contained. Note: six antenna matching-option pad pairs
are deliberately unrouted in the shipped design and are recorded as DRC
exclusions — see the porting notes.
