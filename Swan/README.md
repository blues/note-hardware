# Swan
STM32L4R5 in Adafruit Feather form factor 
  - Schematics
  - Bills of material
  - PCB layouts and Gerber files
  - Dimensioned drawings
  - 3D Models
  - Eagle Library files for Swan Carrier

No KiCad port is provided for Swan: v3.0 was authored in OrCAD/Allegro,
for which no KiCad importer exists.
