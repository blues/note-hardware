Battery Charger w/ Power Path

Battery Charger w/ Power Path design notes

  • Copyright © 2023 Blues Inc.
  • Charger default charging voltage: 4.2V
  • Charger default charging current: 320mA
  • Charger default termination current: 20mA
  • Charger default pre-charge current: 20mA
  • Charger: No battery thermal protection
  • Charger: No battery behaviour: +VBAT is pulled to VUSB - 0.7V through D4 & R20
  • Power Path input current limit: 3.5A
  • Power Path reverse blocking transistor: 26mOhm
  • Power Path battery transistor: 15mOhm
  • Buck Regulator frequency: 1.5MHz
  • Buck Regulator input voltage: 4.5–5.5V
  • Buck Regulator output voltage: 3.3–4.2V
  • Buck Regulator peak current: 1.6A
  • Battery cable configuration note is present, but details are not readable.
