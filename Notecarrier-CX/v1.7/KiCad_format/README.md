# Notecarrier-CX v1.7 — KiCad format

This directory contains the design files for the Blues **Notecarrier-CX**
v1.7 in **KiCad 9** format. They were generated by porting the original
Altium Designer design files (project `100544_notecarrier-cx`) and validated
against the shipped BOM, the production gerbers, and the shipped ODB++
netlist — see
[`documentation/Porting-Notes.md`](documentation/Porting-Notes.md) and
[`validation/`](validation/).

## Contents

| Path | Description |
|---|---|
| `Notecarrier-CX.kicad_pro` / `Notecarrier-CX.kicad_prl` | KiCad project |
| `Notecarrier-CX.kicad_sch` | Root schematic |
| `Notecarrier-CX_IO-Connection.kicad_sch`, `Notecarrier-CX_Notecard-Connection.kicad_sch`, `Notecarrier-CX_Power.kicad_sch`, `Notecarrier-CX_MCU.kicad_sch` | Child sheets (the Altium cover and block-diagram sheets are not ported) |
| `Notecarrier-CX.kicad_pcb` | 4-layer board (castellated edges; zone fills preserved from the Altium import — do not refill) |
| `Notecarrier-CX.kicad_wks` | Drawing sheet (shared Blues template) |
| `Notecarrier-CX-altium-import.kicad_sym` / `Notecarrier-CX-altium-import.pretty/` | Project symbol/footprint libraries captured during the import |
| `sym-lib-table` / `fp-lib-table` | Library tables (the original Altium lib nicknames are aliased to the project library) |
| `documentation/` | Porting notes and plotted schematic/board PDFs |
| `manufacturing/Notecarrier-CX_RevA.zip` | Gerbers + Excellon drills exported from KiCad (authoritative production package: [`../FAB/`](../FAB/) ) |
| `validation/` | ERC/DRC reports, per-layer gerber diffs, BOM comparison, ODB++ netlist cross-check, KiCanvas screenshots |

The project is self-contained. Note: R4 (0R) is not populated in the
production build and is flagged DNP; the castellated header positions
P1/P2/P4 are bare-board features and are excluded from the BOM, matching
the shipped production BOM.
