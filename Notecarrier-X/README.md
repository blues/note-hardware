# Notecarrier X

  - Schematics
  - Bills of material
  - PCB layouts and Gerber files
  - Dimensioned drawings
  - 3D models

No KiCad port is provided for this product: the exact Altium sources
matching the published fabrication package are not available, and a
conversion from a near-miss source state could not be proven accurate
against the shipped gerbers, so none is published (accuracy over
coverage). See the repository README for the products that do have
validated KiCad ports.
